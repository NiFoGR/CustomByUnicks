# UNICKS: Luxury Bathrooms

Website for **UNICKS** (`@custombyunicks`). Static HTML generated by a small Python
script, hosted free on GitHub Pages behind Cloudflare.

The site has one job: turn a visitor into an enquiry by showing **trust**, **expertise**
and **premium quality**. Every page has a single main action (*Price my bathroom*),
risk is removed up front (free survey, fixed written quote, guarantee), and expertise
is shown through specifics rather than adjectives.

---

## Editing

```
src/site.json            business details: city, phone, address, guarantee, areas...
src/pages/*.html         page bodies (home, services hub, work, process, packages, contact, privacy, 404)
src/services/*.json      the 8 service pages (copy, FAQs, image, SEO title/description)
src/partials/            the enquiry form and closing call-to-action
src/layout.html          head, header, footer shared by every page
assets/js/packages-data.js   packages, options and prices
tools/build.py           builds every page into the repo root
tools/images.py          crops and resizes photos from src/originals into assets/img
```

After **any** change in `src/` or `packages-data.js`:

```bash
python3 tools/build.py          # standard library only
python3 -m http.server 8000     # preview at http://localhost:8000
```

Commit the generated HTML too. GitHub Pages serves the files as they are.

New or replaced photos: put the original in `src/originals/`, add its crop to
`PHOTOS` in `tools/images.py`, run `pip install pillow && python3 tools/images.py`.

## Before it goes live

### 1. Fill in `src/site.json`
Every empty value shows on the site as a gold dashed placeholder, so nothing can be
missed. **City is the most important**: the SEO titles, H1s and structured data all use it.

| Key | Used for |
|---|---|
| `city`, `county` | H1s, page titles, schema (category + city is what ranks locally) |
| `street`, `postcode`, `phone`, `email` | NAP: footer of every page, contact page, schema. **Must match the Google Business Profile exactly** |
| `hours`, `areas` | Contact page, footer, FAQ |
| `guaranteeYears` | The guarantee line under every call to action |
| `replyTime` | e.g. "one working day" |
| `legalName`, `companyNo`, `vatNo` | Footer, privacy notice |
| `mapsUrl` | Google Maps link to the profile (added to schema) |

### 2. Real prices in `assets/js/packages-data.js`
**Every price is a placeholder.** So are the package names and options. Change them, rebuild.

### 3. Connect the form
GitHub Pages cannot receive forms. Create a free Formspree (50/month) or Web3Forms
(250/month) form and paste its URL into `FORM_ENDPOINT` at the top of `assets/js/main.js`.
Until then, visitors are asked to message on Instagram instead.

Each enquiry arrives with: the package and options they ticked plus a link to that
build, which page they sent it from, **how they found you**, and any `utm_`/`gclid`
campaign tag. That makes every marketing channel measurable.

### 4. Confirm these claims with him
The copy only states what a premium fitter *should* do. Each line below must be true
for UNICKS, or be edited. Trust built on one false claim is worse than none.

- [ ] **Photos are his completed work.** If any are 3D visuals, say so in the caption
      (a design visual is still strong proof, presented honestly).
- [ ] One team designs and builds; trades are not handed off between companies
- [ ] Whole wet zone is tanked; timber floors overboarded; set-out planned first
- [ ] Valves, cisterns and LED drivers are left with access
- [ ] Fixed, itemised quote; no changes without written approval
- [ ] Notifiable electrical work certified (who does it, which scheme)
- [ ] Public liability insurance (insurer, cover amount)
- [ ] Staged payments (deposit and stage terms)
- [ ] Typical durations in the service pages (marked as placeholders)
- [ ] What's *not* included in packages (packages page FAQ)

Search the built site for `class="ph"` to list every remaining placeholder.

## SEO: what is done on the site, what is left off-site

Done on the site (from the local SEO playbook):

- **Title tags** = service + city + brand, e.g. *Wet Rooms [City] | Luxury Wet Room Design & Installation | UNICKS*.
  Deliberately not "BEST ..." and not 200 characters: Google cuts titles at about 60
  characters and often rewrites stuffed ones, and shouting reads cheap on a luxury brand.
- **H1** = category + city on every page; **H2s** name the services.
- **NAP** in the footer of every page and on the contact page, from one source.
- **Schema**: `HomeAndConstructionBusiness` on every page, plus `Service`,
  `FAQPage` and `BreadcrumbList` where relevant. Check at validator.schema.org.
- **Page count**: 16 pages, including 8 service pages of 1,100 to 1,400 words each with
  real technical depth (topical authority), interlinked with natural anchor text.
- `sitemap.xml` and `robots.txt`.

Left to do, mostly off-site:

1. **Google Business Profile**: 1 primary category (*Bathroom remodeler*), at most 2 to
   3 more; 30+ services with 300-character descriptions (the 8 service pages are a
   ready source); booking link → `https://unicks.co.uk/contact/`; FAQs; weekly photos.
2. **Area pages**: once his areas are known, add `src/pages/area-<town>.html` pages
   (one per town, 1,200+ words of genuinely local content) and link them from the
   contact page and footer. That takes the site past 30 indexed pages.
3. **Citations**: Bing Places, Apple Business Connect, Yell, Foursquare, plus whichever
   directories rank for "bathroom fitters [city]". Same NAP everywhere.
4. **Reviews**: there are none yet, so the site deliberately has no review section
   (no empty stars, nothing invented). Ask every client at handover. When a few exist,
   add a reviews block and `aggregateRating` to the schema.
5. **Google Search Console**: submit `sitemap.xml`.

## Performance & privacy

- No third-party requests at all: fonts are self-hosted, no analytics, no cookies.
  That also means no cookie banner is needed (see the privacy notice).
- Images are WebP with JPEG fallback at 640/1080 wide, with fixed dimensions (no
  layout shift). The hero image loads first with high priority; everything else lazy-loads.
- Packages and options are rendered into the HTML at build time, so the page does not
  jump when scripts run, and the prices can be indexed.
- Measured locally: layout shift 0.000 on every page; heaviest page (home on mobile) about 530 KB.

## Motion

Slow, eased, transform and opacity only, so it never causes layout shift. The hero text
rises in once fonts load, and the hero photo settles from a slight zoom. Sections and
images reveal once as they enter, staggered within each group. Buttons fill from below
and links draw an underline. The header goes solid after scrolling and hides while you
scroll down. The package total counts up to its new value. All of it switches off
under the system's *reduce motion* setting.

## Hosting: GitHub Pages + Cloudflare, two domains

**unicks.co.uk** is the site. **unicksbathroom.co.uk** permanently redirects to it
(GitHub Pages serves one custom domain per repo, and one canonical domain is better for Google).

1. **GitHub Pages**: Settings → Pages → Deploy from branch → your main branch, `/ (root)`.
   Free only for public repos. The `src/` and `tools/` folders are published too; they contain nothing private.
2. **unicks.co.uk** on Cloudflare, records **DNS only (grey cloud)** to start:

   | Type | Name | Content |
   |---|---|---|
   | A | `@` | 185.199.108.153 |
   | A | `@` | 185.199.109.153 |
   | A | `@` | 185.199.110.153 |
   | A | `@` | 185.199.111.153 |
   | CNAME | `www` | `nifogr.github.io` |

   Then GitHub → Pages → Custom domain `unicks.co.uk`, and tick **Enforce HTTPS**
   once the certificate is issued. If you later turn the orange cloud on, set
   SSL/TLS to **Full** (never Flexible: it loops).
3. **unicksbathroom.co.uk**: add to Cloudflare, `A @ 192.0.2.1` and `CNAME www @`,
   both **proxied**; Rules → Redirect Rules → all requests → dynamic
   `concat("https://unicks.co.uk", http.request.uri.path)`, **301**, keep query string.

The site uses relative links, so it also previews correctly at
`https://nifogr.github.io/CustomByUnicks/` before the domain is connected
(except the 404 page, which only works on the real domain).
